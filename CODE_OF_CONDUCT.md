# Code of Conduct

This project adopts the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) by
reference — see that page for the full text, which this file does not
copy.

## Reporting

Report unacceptable behavior through GitHub's private vulnerability/abuse
reporting for this repository (repository → **Security** tab → **Report a
vulnerability**, or, for conduct rather than security issues, contact the
maintainers privately through your GitHub account settings). Please do
not open a public issue for a conduct report.
